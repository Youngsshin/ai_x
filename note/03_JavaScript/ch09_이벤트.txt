이벤트 정리

1절 이벤트 관련 용어
- 이벤트 : 키보드 입력, 마우스 클릭 등 다른 것에 영향을 미치는 것
- 이벤트 연결 : 객체의 이벤트 속성에 함수를 할당하는 것
- 이벤트 이름 : click, load, mouseover 등
- 이벤트 속성 : onclick, onload, onmouseover 등 (on + 이벤트명)
- 이벤트 리스너 : 이벤트 발생시 실행되는 함수

2절 이벤트 모델 3가지
- 인라인 이벤트 모델 : HTML 태그에 직접 이벤트 속성 작성
- 기본 이벤트 모델 : 이벤트 속성에 함수 할당, this 키워드 사용 가능
- 표준 이벤트 모델 : addEventListener() 메서드 사용

3절 이벤트 강제 실행
- 이벤트 속성에 할당된 함수를 직접 호출하여 강제 실행
- 다른 이벤트 발생시 연동하여 실행하는 경우에 활용
- 객체.onclick() 형태로 호출

4절 디폴트 이벤트 제거
- HTML 태그가 기본으로 가지고 있는 이벤트 동작 제거
- return false 또는 이벤트 속성을 null로 설정
- form 태그의 submit, a 태그의 링크 이동 등을 제어

5절 이벤트 객체 활용
- event.keyCode : 입력된 키의 아스키 코드값
- event.offsetX, event.offsetY : 클릭한 곳의 offset 좌표
- event.screenX, event.screenY : 클릭한 곳의 screen 좌표
- 키보드 이벤트와 마우스 이벤트에서 상세 정보 활용 가능
