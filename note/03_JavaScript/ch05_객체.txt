JavaScript 객체 정리

1절 객체 개요
- 객체 : 서로 연관된 변수와 함수를 그룹핑한 것
- 생성 : var product = { 제품명: '망고', 유형: '당절임' }
- 접근 : product['제품명'] 또는 product.제품명
- 배열(요소element)과 다른 개념 : 객체(속성property)

2절 속성과 메서드
- 속성(property) : 객체 내부의 변수
- 메서드(method) : 객체 내부의 함수
- this 키워드 : 객체 자기 자신을 참조 (생략 불가)
- 메서드 호출 : 객체명.메서드명()

3절 객체와 반복문
- for-in 반복문만 사용 가능 (일반 for문 불가)
- for (var key in 객체) { 객체[key] }
- 속성명을 key 변수에 저장하여 순회

4절 속성 추가와 제거
- 속성 추가 : 객체.새속성 = 값 또는 객체['새속성'] = 값
- 메서드 추가 : 객체.메서드명 = function() { 실행문 }
- 속성 제거 : delete(객체.속성명) 또는 delete 객체.속성명
- 동적으로 속성과 메서드 조작 가능

5절 객체와 배열 조합
- 객체의 배열 : [{ name: '홍길동', age: 20 }, { name: '김길동', age: 25 }]
- 배열의 객체 : { students: ['홍길동', '김길동'], scores: [90, 85] }
- 복잡한 데이터 구조 표현에 활용
- 반복문으로 일괄 처리 가능

6절 함수를 이용한 객체 생성
- 객체 생성 함수 : function makeObject(매개변수) { return 객체; }
- 같은 구조의 객체 여러 개 생성시 유용
- 생성자 함수 패턴 : 코드 재사용성 향상
- 메서드도 함께 생성하여 완전한 객체 제작
