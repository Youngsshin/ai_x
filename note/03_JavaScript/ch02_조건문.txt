JavaScript 조건문 정리

1절 if 조건문
- if (조건식) { 실행문 }
- if (조건식) { 참 실행문 } else { 거짓 실행문 }
- if~else if~else : 여러 조건 분기
- 중첩 조건문 : if문 안에 또 다른 if문

2절 switch 조건문
- switch (비교할 값) { case 값: 문장; break; default: 문장; }
- break 없으면 다음 case도 실행 (fall-through)
- 여러 case를 하나로 묶기 가능 : case 1: case -1: 실행문;
- 정확히 일치하는 값으로만 비교 가능

3절 삼항 연산자
- (조건식) ? 참일 때 값 : 거짓일 때 값
- 간단한 조건문을 한 줄로 표현
- 중첩 사용 가능하지만 가독성 주의

4절 내장 객체 활용
- Date 객체 : new Date(), getHours(), getDay() 등
- Math 객체 : 수학 관련 메서드들
- document 객체 : 웹페이지 조작

5절 조건문 활용 예시
- 시간대별 인사말 출력
- 요일별 배경색 변경  
- 사용자 입력값 검증
- 점수 구간별 등급 판정
