기본객체 정리

1절 String 객체
- 문자열을 다루기 위한 내장 객체
- 주요 속성 : length (문자열 길이)
- 주요 메서드 : concat(), substr(), indexOf(), lastIndexOf(), slice(), toUpperCase()
- 정규표현식과 함께 사용하여 패턴 검증 가능 (test() 메서드)
- 메서드는 원본을 변경하지 않고 새로운 문자열 리턴

2절 Array 객체
- 배열을 만들어 주는 객체
- 생성 방법 : 리터럴 표기법 또는 new Array() 생성자
- 주요 메서드 : sort(), push(), pop(), slice()
- sort() 메서드는 기본적으로 문자열 정렬
- 숫자 정렬을 위해서는 비교 함수를 매개변수로 제공 필요
- 학생 성적 정렬 등 복잡한 객체 배열 정렬 가능

3절 Date 객체
- 날짜와 시간을 처리하기 위한 객체
- 생성자 매개변수 순서 : 연, 월-1, 일, 시, 분, 초, 밀리초
- 주요 메서드 : getFullYear(), getMonth(), getDate(), getTime()
- 날짜 간격 계산 : getTime() 사용하여 밀리초 단위로 계산
- 프로토타입에 메서드 추가하여 기능 확장 가능
- 외부 파일로 분리하여 재사용 가능

4절 Math 객체
- 수학 계산을 위한 객체
- 생성자 함수 없이 바로 사용하는 정적 객체
- 주요 속성 : PI, E 등의 수학 상수
- 주요 메서드 : max(), min(), round(), random(), floor(), ceil()
- 변수에 할당하여 간편하게 사용 가능
