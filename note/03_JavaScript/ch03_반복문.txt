JavaScript 반복문 정리

1절 배열
- 생성 : var array = [273, 32, 103, 57, 52]
- 다양한 자료형 저장 가능 : [273, 'String', true, function(){}, {}]
- 속성/메서드 : length(길이), push(끝에추가), pop(끝에서제거)
- unshift(앞에추가), shift(앞에서제거), includes(포함여부)

2절 while 반복문
- while (조건식) { 실행문 }
- 조건이 참인 동안 계속 반복
- 무한루프 주의 (조건이 항상 참인 경우)

3절 do-while 반복문
- do { 실행문 } while (조건식);
- 최소 한 번은 실행 후 조건 검사
- 사용자 입력 검증에 유용

4절 for 반복문
- for (초기값; 반복조건; 증감식) { 실행문 }
- 실행순서 : ①초기값 → ②조건검사 → ③실행문 → ④증감식 → ②조건검사...
- 배열 순회에 주로 사용

5절 for-in 반복문
- for (var i in array) { 실행문 }
- 배열의 인덱스나 객체의 속성명을 순회
- 인덱스 값을 변수에 저장

6절 forEach 함수
- array.forEach(function(data, index) { 실행문 })
- 배열의 각 요소와 인덱스를 매개변수로 전달
- 콜백함수를 이용한 반복 처리

7절 제어문
- break : 반복문 즉시 종료
- continue : 현재 반복 건너뛰고 다음 반복으로
- 중첩 반복문에서 원하는 반복문만 제어 가능
