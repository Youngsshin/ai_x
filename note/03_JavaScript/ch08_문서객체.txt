문서 객체 모델 정리

1절 문서 객체 모델 개요
- HTML 페이지를 인식하는 방식, document 객체와 관련된 객체 집합
- 태그를 자바스크립트에서 이용할 수 있는 객체로 만든 것이 문서 객체
- 트리 모양의 구조로 각 요소를 노드라고 부름
- 정적 생성 : HTML에서 읽어들인 태그, 동적 생성 : 자바스크립트로 생성한 객체

2절 문서 객체 만들기(텍스트 노드)
- document.createElement() : 요소 노드 생성
- document.createTextNode() : 텍스트 노드 생성
- appendChild() : 노드 연결
- 노드 생성 후 반드시 DOM 트리에 연결해야 화면에 표시

3절 문서 객체 만들기(속성)
- 텍스트 노드를 갖지 않는 태그(img, input 등) 처리
- setAttribute() : 속성 설정
- 직접 속성 할당도 가능 : img.src = '경로'

4절 innerHTML 사용
- innerHTML 속성에 HTML 문자열 할당하여 간편하게 요소 생성
- 문자열로 태그 구조를 작성하여 한 번에 삽입
- 기존 내용 대체 또는 추가(+=) 가능

5절 문서 객체 가져오기(ID)
- getElementById() : id 속성으로 문서 객체 가져오기
- 하나의 객체만 리턴 (id는 고유값)
- 가장 일반적이고 많이 사용하는 방법

6절 문서 객체 가져오기(다양한 방법)
- getElementsByClassName() : class명으로 배열 형태로 가져오기
- getElementsByName() : name 속성으로 배열 형태로 가져오기
- getElementsByTagName() : 태그명으로 배열 형태로 가져오기
- 배열 형태로 리턴되므로 인덱스나 반복문으로 접근

7절 문서 객체 가져오기(CSS 선택자)
- querySelector() : CSS 선택자로 첫 번째 요소만 가져오기
- querySelectorAll() : CSS 선택자로 모든 요소를 배열로 가져오기
- #id, .class, 태그명 등 CSS 선택자 문법 사용 가능

8절 문서 객체 스타일 조작
- style 속성으로 CSS 스타일 변경
- CSS 속성명에서 하이픈(-)을 카멜케이스로 변경 : font-family → fontFamily
- cssText 속성으로 여러 스타일을 한 번에 설정 가능

9절 문서 객체 제거
- removeChild() : 자식 노드 제거
- 부모.removeChild(자식) 형태로 사용
- 배열로 가져온 요소들을 제거할 때는 뒤에서부터 제거해야 인덱스 오류 방지

10절 문서 객체 활용
- 시계 만들기 : setInterval과 Date 객체 조합
- 동적 스타일 변경 : 색상 배열과 카운터 활용
- 마우스 이벤트와 DOM 조작을 결합한 인터랙티브 페이지 구현
