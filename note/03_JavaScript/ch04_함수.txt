JavaScript 함수 정리

1절 익명함수
- 함수 표현식 : var func = function() { 실행문 }
- 화살표 함수 : var func = () => { 실행문 }
- 변수에 저장해서 사용 : func()로 호출
- 함수도 하나의 자료형 (typeof 결과는 function)

2절 선언적 함수
- 함수 선언식 : function 함수명() { 실행문 }
- 호이스팅 : 스크립트 실행 전에 먼저 읽혀짐
- 함수 재정의 가능 (나중에 선언한 함수가 우선)
- 익명함수와 선언적 함수 실행 순서 차이점 존재

3절 매개변수와 리턴값
- function 함수명(매개변수1, 매개변수2) { return 값; }
- 매개변수 개수가 맞지 않아도 실행 가능
- 부족한 매개변수는 undefined, 초과한 매개변수는 무시
- return문 없으면 undefined 반환

4절 가변인자 함수
- arguments 객체 : 전달받은 모든 매개변수 배열
- arguments.length : 매개변수 개수
- arguments[인덱스] : 특정 매개변수 접근
- Array() 함수처럼 매개변수 개수에 따라 다르게 동작

5절 내부함수
- 함수 안에 선언하는 함수
- 함수명 충돌 방지 효과
- 내부함수가 외부 동명 함수보다 우선
- jQuery 등에서 많이 사용하는 패턴

6절 콜백함수
- 매개변수로 전달되는 함수
- function callback(콜백함수) { 콜백함수(); }
- 익명함수로 직접 전달하는 경우가 많음
- 이벤트 처리, 배열 처리 등에 활용

7절 클로저
- 함수에서 함수를 반환하는 구조
- 반환된 함수가 외부 지역변수에 접근 가능
- 각 클로저마다 고유한 지역변수 유지
- 데이터 은닉과 캡슐화에 활용

8절 내장함수
- setTimeout(함수, 밀리초) : 일정시간 후 한번 실행
- setInterval(함수, 밀리초) : 일정시간마다 반복 실행
- clearTimeout(id), clearInterval(id) : 타이머 중지
- 타이머 함수는 브라우저가 처리하는 비동기 함수
