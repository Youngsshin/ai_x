jQuery 정리

1절 jQuery 소개
- 자바스크립트 라이브러리 중 가장 인기 있는 라이브러리
- 이벤트 대응, 애니메이션, 메뉴 효과 등을 단순하고 쉽게 구현
- 문서 객체 모델 처리, 일관된 이벤트 연결, 시각적 효과, Ajax 개발 지원
- "적게 쓰고 큰 효과"를 목적으로 하는 경량화된 라이브러리

2절 사용법
- 다운로드 방식 : jQuery.com에서 파일 다운로드 후 로컬에서 사용
- CDN 방식 : 구글 등의 CDN에서 직접 로드
- CDN 방식이 캐싱 효과로 더 빠른 로딩 가능
- script 태그로 jQuery 라이브러리를 먼저 포함시켜야 함

3절 기본 문법
- 기본 형태 : $('선택자').함수()
- $ 기호가 jQuery를 의미
- 주요 함수 : html(), text(), val(), css()
- 이벤트 함수 : click(), focus() 등
- Document Ready 이벤트 : $(document).ready() 또는 $()

4절 Ajax 
- 서버와 데이터 교환을 하는 기술
- 웹페이지 전체를 다시 로딩하지 않고 특정 부분만 업데이트
- 주요 메서드 : $.get(), $.post(), $.ajax()
- $.ajax()는 JSON 형식으로 옵션 설정
- url, type, data, dataType, success, error 옵션 사용
- 콜백함수로 성공/실패 처리
