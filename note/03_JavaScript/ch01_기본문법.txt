JavaScript 기본문법 정리

1절 기본 용어
- 표현식과 문장 : 하나 이상의 표현식이 모여 문장. 문장 끝에 세미콜론
- 키워드 : JavaScript 예약어 (break, else, for, if, this, while 등)
- 식별자 : 변수명, 함수명 등 (키워드 사용금지, 숫자로 시작금지, _ $ 만 허용)
- 주석 : /* */ 또는 //

2절 변수 선언
- var : 변수 재선언 가능, 전역변수 (함수 스코프)
- let : 변수 재선언 불가, 블록 레벨 스코프
- const : 재할당 불가, 상수 (객체 내부값은 변경 가능)

3절 자료형
- string : 문자열 ('', "" 모두 가능, 이스케이프 문자 사용)
- number : 정수/실수 구분 없음 (10진수, 8진수, 16진수, 지수형)
- boolean : true/false
- object : 배열, 객체 등
- function : 함수형
- undefined : 초기화하지 않은 변수

4절 연산자
- 산술연산 : + - * / % (문자열+숫자 = 문자열)
- 복합대입 : += -= *= /= %=
- 증감연산 : ++, --
- 비교연산 : > >= < <= == != === !==
- 논리연산 : && || !
- 삼항연산 : 조건식 ? 참 : 거짓

5절 자료형 변환
- Number(값) : 숫자로 변환 (변환 불가시 NaN)
- parseInt(문자열), parseFloat(문자열) : 정수/실수 변환
- String(값) : 문자열로 변환
- Boolean(값) : 불린형 변환 (0, NaN, '', null, undefined, false는 false)
- isNaN(값) : 숫자인지 확인

6절 자료형 검사
- typeof(변수) : 자료형 확인
- === : 값과 자료형 모두 비교 (완전일치)
- == : 값만 비교 (형변환 후 비교)

7절 내장 대화상자 함수
- alert(메시지) : 경고창 출력
- confirm(메시지) : 확인/취소 선택창 (true/false 반환)
- prompt(메시지, 초기값) : 문자 입력창 (문자열 반환)
