자연어 처리 패키지 정리

1절 NLTK 자연어 처리 패키지

교육용으로 개발된 파이썬 자연어 처리 패키지
주요 기능: 말뭉치(corpus), 토큰화, 형태소 분석, 품사 태깅
Penn Treebank 데이터 (400만 어절 규모) 제공
토큰화: sent_tokenize() (문장 단위), word_tokenize() (단어 단위)
어간 추출: PorterStemmer, LancasterStemmer, SnowballStemmer
원형 복원: WordNetLemmatizer (의미 보존)
품사 태깅: pos_tag() 함수로 단어별 품사 부착
FreqDist 클래스로 단어 빈도수 분석

2절 한글 형태소 분석과 워드 클라우드

자연어: 사람이 일상적으로 사용하는 언어
형태소: 의미를 가진 최소 단위 (실질 형태소, 형식 형태소)
KoNLPy 패키지: 한국어 정보처리용 파이썬 패키지
주요 형태소 분석기: Hannanum, Kkma, Komoran (각각 고유한 품사 태그 체계)
워드클라우드: 단어 출현 빈도를 크기로 시각화 (한글 폰트 설정 필요)
Word2Vec: 희소 표현을 밀집 표현으로 변환하는 워드 임베딩

3절 연관분석

데이터 간 자주 발생하는 속성과 연관성 정도 분석
Apriori 알고리즘 사용 (apyori 패키지)
평가 지표: 지지도(Support), 신뢰도(Confidence), 향상도(Lift)
트랜잭션 데이터: 리스트의 리스트 형식
namedtuple로 결과 저장 (RelationRecord, OrderStatistic)

4절 케라스를 이용한 인공신경망 구현

인공신경망 구성: 입력층, 은닉층, 출력층
활성화 함수: ReLU, Sigmoid, Softmax 등
케라스: 딥러닝 모델을 쉽게 구현하는 고급 API
Sequential 모델: 층을 순차적으로 쌓는 방식
옵티마이저: SGD, Adam, RMSprop 등
CNN 모델 구현: Convolution, Pooling, Dense 층 조합

5절 RNN

순환신경망: 시퀀스 데이터 처리용 신경망 (1986년 David Rumelhart 개발)
은닉 상태를 다음 시점으로 전달하는 구조
RNN 종류: One-to-Many, Many-to-One, Many-to-Many
양방향 RNN: 순방향과 역방향 정보를 모두 활용
LSTM: RNN의 단기 기억 문제 해결 (Long Short-Term Memory)
GRU: LSTM을 단순화하여 속도 개선 (Gated Recurrent Unit)
실습: IMDB 영화평 분류 (Embedding → RNN → Dense)
