모바일 레이아웃과 반응형 웹 정리

1. Viewport (뷰포트)
- 모바일 웹브라우저에서 화면 설정 관련 정보를 제공하는 메타 태그
- 스마트폰 화면 크기에 관계없이 항상 꽉 차게 표시
- 속성 : width(화면너비), height(화면높이), initial-scale(초기확대비율)
         user-scalable(확대축소가능여부), minimum-scale(최소비율), maximum-scale(최대비율)

2. 모바일 레이아웃 구조
- Header : 로고, 검색, 메뉴 아이콘 배치
- LNB(Local Navigation Bar) : 주요 메뉴 버튼들 가로 배치
- Section : 다양한 콘텐츠 영역 (이미지갤러리, 텍스트목록, 혼합형)
- Footer : 회사정보, 연락처, 저작권 표시

3. 모바일 UI 설계 원칙
- 터치 버튼 최소 크기 : 44px x 44px 이상
- 텍스트 최소 크기 : 16px 이상
- 말줄임 처리 : white-space:nowrap, overflow:hidden, text-overflow:ellipsis
- 반응형 너비 : 퍼센트(%) 기반 설정

4. 모바일 개발 기법
- Float 레이아웃 : 이미지와 텍스트 나란히 배치
- Position 절대위치 : 검색창 내 아이콘 고정 배치
- Box-sizing:border-box : 패딩과 보더를 포함한 전체 크기 계산
- Overflow:hidden : Float 해제 및 콘텐츠 넘침 처리

5. 개발 도구 및 테스트
- Chrome 개발자도구 : F12 → Ctrl+Shift+M (모바일 모드)
- 다양한 기기 해상도에서 테스트 필수
- 터치 동작 시뮬레이션 가능
- 실제 기기에서 최종 검증 필요

6. 반응형 웹 (@media 쿼리)
- CSS 파일 분리 : link태그 media 속성 활용
- @import 규칙 : CSS 내부에서 다른 CSS 불러오기
- @media 규칙 : 화면 크기별 다른 스타일 적용
- 미디어 타입 : all(모든미디어), print(인쇄용), screen(화면용)

7. 반응형 설계 구간
- 모바일 : ~959px (max-device-width:959px)
- 태블릿 : 960px~1200px (min-device-width:960px and max-device-width:1201px)  
- 데스크톱 : 1201px~ (min-device-width:1201px)
- 각 구간별 레이아웃과 스타일 최적화 필요
