HTML 기초 정리

1절 HTML 기본 구조
- HTML 구조 : <!DOCTYPE html> → <html> → <head>/<body> → </html>
- 태그 구성 : 이름, 속성, 속성값으로 구성 (열린태그+닫힌태그 쌍)
- HEAD 태그 : meta, title, script, link, style만 포함 가능
- BODY 태그 : 사용자에게 보이는 실제 웹 문서 내용

2절 글자 관련 태그
- 제목태그 : h1~h6 (h1이 가장 크고 중요, 개행 포함)
- 본문태그 : p(문단, 16px 기본), br(줄바꿈), hr(수평선)
- 서식태그 : b(굵게), i(이탤릭), sup(위첨자), sub(아래첨자), del(취소선)
- 링크태그 : a href="URL" target="_blank" (하이퍼링크)

3절 목록/표/이미지 태그
- 목록 : ul(순서없음), ol(순서있음), li(목록요소)
- 표 : table → tr(행) → th(제목셀), td(일반셀)
- 병합 : rowspan(행병합), colspan(열병합)
- 이미지 : img src="경로" alt="대체텍스트"
- 멀티미디어 : audio, video (HTML5 추가기능)

4절 Form 태그 (입력양식)
- Form 구조 : action(전송위치), method(get/post)
- Input 타입 : text, password, radio, checkbox, file, submit, reset
- HTML5 추가 : email, tel, date, color, range, number
- 향상 기능 : required(필수), placeholder(힌트), autofocus(자동포커스)
- 기타 요소 : textarea, select, option, label, fieldset, legend

5절 레이아웃 태그
- 공간분할 : div(블록), span(인라인)
- 시맨틱 태그 : header, nav, section, article, aside, footer
- 블록 vs 인라인 : 개행포함여부, 너비/높이 설정가능여부

6절 웹 표준 및 유효성 검사
- DTD 선언 : <!DOCTYPE html> (문서 첫 번째 줄)
- 웹 접근성 : alt 속성, label 연결, 시맨틱 태그 활용
- 유효성 검사 : 브라우저 호환성, 검색엔진 최적화, 유지보수 효율성
- JavaScript 검증 : trim(), focus(), length 속성 활용
