2절. 텐서플로우 케라스
케라스 vs 파이토치

케라스: 높은 수준 API, 직관적, TensorFlow 통합
파이토치: 낮은 수준 API, 유연함, 연구 커뮤니티 선호

주요 모듈

tf.keras.Sequential: 순차 모델 구축
tf.keras.layers: 다양한 층 정의 (Dense, Conv2D 등)
tf.keras.losses: 손실 함수 (categorical_crossentropy 등)
tf.keras.optimizers: 최적화 알고리즘 (Adam, SGD 등)

모델 구축 방법

Sequential API: 단순한 층 쌓기
Functional API: 복잡한 모델 구조 (다중 입출력 등)

3절. 합성곱 신경망 기초
이미지 합성곱

필터(커널)을 이미지에 적용하여 특징 추출
필터 크기만큼 요소별 곱셈 후 합계 계산
다양한 필터: Sobel, Prewitt, Sharpen, Blur 등

풀링(Pooling)

Max Pooling: 영역 내 최댓값 선택
Average Pooling: 영역 내 평균값 계산
차원 축소로 연산량 감소 및 특징 강화

스트라이드와 제로 패딩

스트라이드: 필터 이동 크기 (일반적으로 합성곱 1, 풀링은 풀 사이즈와 동일)
제로 패딩: 바깥 화소 손실 방지, floor(filter_size/2)만큼 0 추가
padding='same': 제로패딩 사용, padding='valid': 제로패딩 미사용

4절. CNN 모델 구조
전체 구조

Feature Extraction: Convolution → Pooling 반복
Classification: Fully Connected Layer로 분류

Channel 구조

TensorFlow: Channel Last (height, width, channel)
PyTorch: Channel First (channel, height, width)
