# Sequence 정리

1절 Sequence의 정의와 특징
- 순차적인 번호를 자동으로 생성하는 객체
- 테이블과 독립적으로 생성 및 저장 가능
- 생성되는 번호는 유일하여 인조 Primary Key 생성시 주로 사용
- 여러 테이블에서 공유 가능

2절 Sequence 생성 문법
- CREATE SEQUENCE sequence_name [INCREMENT BY n] [START WITH n] [MAXVALUE n] [MINVALUE n] [CYCLE|NOCYCLE] [CACHE n|NOCACHE]
- INCREMENT BY: 증가값 설정
- START WITH: 시작값 설정
- MAXVALUE/MINVALUE: 최대/최소값 설정
- CYCLE: 최대값 도달 후 최소값부터 재시작 여부
- CACHE: 메모리에 미리 생성할 값의 개수

3절 Sequence 사용법
- NEXTVAL: 다음 값 생성 및 반환
- CURRVAL: 현재 값 반환 (NEXTVAL 사용 후에만 가능)
- INSERT문에서 sequence_name.NEXTVAL 형태로 사용
- 자동 증가하는 고유한 키 값 생성에 활용

4절 Sequence 관리
- 삭제: DROP SEQUENCE sequence_name
- 수정: ALTER SEQUENCE sequence_name [옵션들]
- 시작값(START WITH)은 수정 불가능
- 테이블과 독립적이므로 테이블 삭제와 별도로 관리
