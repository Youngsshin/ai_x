# DDL, DML, DCL 정리

1절 SQL문의 종류
- DML (Data Manipulation Language): INSERT, DELETE, UPDATE, SELECT
- DDL (Data Definition Language): CREATE, DROP
- DCL (Data Control Language): GRANT, REVOKE, COMMIT, ROLLBACK

2절 CREATE TABLE로 테이블 생성
- 기본 문법: CREATE TABLE table_name (column_name data_type, ...)
- 주요 데이터 타입: VARCHAR2(크기), NUMBER(전체자리, 소수점자리), DATE
- LOB 타입: 최대 4GB까지 대용량 데이터 저장 가능
- 식별자 명명규칙: 문자로 시작, A~Z/0~9/특수기호(_,$,#), 1~30글자

3절 DROP TABLE로 테이블 삭제
- 문법: DROP TABLE table_name
- 기존 테이블을 완전히 제거
- 참조 관계가 있는 경우 자식 테이블부터 삭제해야 함

4절 INSERT문으로 데이터 삽입
- 문법: INSERT INTO table_name (column_list) VALUES (value_list)
- NULL값 삽입: 명시적(NULL 입력) 또는 암시적(컬럼 생략)
- 서브쿼리를 사용한 대량 데이터 삽입 가능

5절 UPDATE문으로 데이터 수정
- 문법: UPDATE table_name SET column=value WHERE condition
- WHERE절 없으면 모든 행이 수정됨 (주의 필요)
- 여러 컬럼 동시 수정 가능 (콤마로 구분)
- 서브쿼리를 사용한 조건부 수정 가능

6절 DELETE문으로 데이터 삭제
- 문법: DELETE FROM table_name WHERE condition
- WHERE절 없으면 모든 행 삭제
- 서브쿼리를 사용한 조건부 삭제 가능

7절 테이블 제약조건
- NOT NULL: NULL값 입력 금지
- UNIQUE: 중복값 입력 금지
- PRIMARY KEY: 기본키 설정 (NOT NULL + UNIQUE)
- FOREIGN KEY: 외래키 설정 (참조 무결성)
- CHECK: 특정 조건을 만족하는 값만 입력 허용
- DEFAULT: 기본값 설정
