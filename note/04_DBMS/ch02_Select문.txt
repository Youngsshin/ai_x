# Select문 정리

1절 기본 문법과 작성법
- 기본 구조: SELECT [DISTINCT] {*, column [Alias]} FROM 테이블명 [WHERE condition] [ORDER BY column [ASC|DESC]]
- SQL문은 대소문자 구별하지 않음, 명령어 끝은 세미콜론(;)
- 주석처리는 -- 사용
- 일반적으로 키워드는 대문자로 작성

2절 기본 조회와 별칭
- SELECT * FROM 테이블명: 모든 컬럼 조회
- 특정 컬럼 조회: SELECT empno, ename FROM emp
- 별칭(Alias) 사용: AS 키워드 사용하거나 생략 가능
- 공백이 포함된 별칭은 큰따옴표로 묶어야 함

3절 WHERE 조건절과 비교연산자
- 같다(=), 크거나같다(>=), 작거나같다(<=), 다르다(<>, ^=, !=)
- 문자열이나 날짜는 반드시 작은따옴표 안에 표시
- 데이터 값은 대소문자 구분함

4절 논리연산자
- AND, OR, NOT 연산자 사용
- 여러 조건을 조합하여 복잡한 조회 조건 생성 가능

5절 산술표현식과 NULL 처리
- 사칙연산 가능: +, -, *, /
- NULL값을 포함한 산술표현식 결과는 NULL
- NVL(expr1, expr2): NULL값을 다른 값으로 변환

6절 연결연산자와 중복제거
- 연결연산자(||): 열이나 문자를 다른 열에 연결
- DISTINCT: 중복 행 제거, 기본적으로 오름차순 정렬

7절 SQL 연산자
- BETWEEN a AND b: a부터 b까지 범위 조회
- IN(list): 리스트 값 중 하나와 일치
- LIKE pattern: 패턴 검색 (%: 0개 이상 문자, _: 1개 문자)
- IS NULL / IS NOT NULL: NULL값 검사

8절 ORDER BY 정렬
- ASC: 오름차순(기본값)
- DESC: 내림차순
- 다중 정렬: 여러 컬럼 기준으로 정렬 가능
- 별칭이나 컬럼 순서번호로도 정렬 가능
