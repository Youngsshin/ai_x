# Join 정리

1절 Join의 필요성
- 2개 이상의 테이블을 연결하여 데이터를 검색하는 방법
- 서로 다른 테이블의 관련 정보를 하나의 결과로 조회할 때 필요
- 한 번의 질의로 여러 테이블의 정보를 동시에 얻을 수 있음

2절 Cross Join
- FROM절에 두 개 이상의 테이블을 기술하되 조인 조건 없이 사용
- 첫 번째 테이블의 모든 행이 두 번째 테이블의 모든 행과 결합
- 실제로는 의미 없는 결과 생성 (카티션 곱)

3절 Equi Join
- 가장 많이 사용하는 조인 방법
- 두 테이블의 공통 컬럼 값이 일치하는 행을 연결
- WHERE절에 조인 조건 명시 (테이블1.컬럼 = 테이블2.컬럼)
- 동일한 이름의 컬럼은 테이블명을 앞에 명시해야 함
- 테이블 별칭(Alias) 사용으로 코드 단순화 가능

4절 Non-Equi Join
- = 연산자 이외의 비교 연산자를 사용한 조인
- 특정 범위 내에 있는지 조사할 때 사용
- BETWEEN 연산자 주로 활용
- 급여 등급 테이블과의 조인이 대표적인 예

5절 Self Join
- 하나의 테이블 내에서 조인을 수행
- 같은 테이블에 대해 두 개의 별칭을 사용
- 사원과 매니저 관계 조회 시 많이 사용
- 계층 구조 데이터 조회에 유용

6절 Outer Join
- 조인 조건에 만족하지 않는 행도 결과에 포함시키는 조인
- (+) 기호를 정보가 부족한 컬럼 뒤에 추가
- 한쪽 테이블에만 데이터가 있어도 결과에 표시
- 직원이 없는 부서나 상사가 없는 사원도 조회 가능
