데이터베이스와 DBMS 정리

1절 파일 시스템 vs 데이터베이스
- 파일 시스템: 별도 구입 비용 없음, 속도 빠름, 저장과 열기 제공
- 데이터베이스: 데이터 독립성, 중복 최소화, 무결성, 공유, 보안관리 제공
- 데이터 집합의 단위: bit > byte > field > record > file > DB

2절 데이터베이스 개념
- 여러 응용 시스템이 공유할 수 있도록 통합, 저장된 운영데이터의 저장소
- 중복을 최소화하여 컴퓨터 기억 장치 내에 모아놓은 데이터 집합
- DBMS: 모든 응용프로그램이 데이터베이스를 공유하도록 관리하는 소프트웨어시스템

3절 DBMS의 기능
- 정의 기능: 데이터의 형태, 구조, 저장에 관한 내용 정의
- 조작 기능: 검색, 갱신, 삽입, 삭제 등을 지원
- 제어 기능: 정확성과 안전성 유지 (무결성, 보안, 복구, 병행수행 제어)

4절 DBMS의 장점
- 데이터 중복의 최소화
- 데이터 공유 가능
- 데이터의 무결성과 일관성 유지
- 데이터 보안 보장
- 자료에 대한 접근성 및 응답성 향상

5절 DBMS의 단점
- 운영비가 많이 듦 (초기 운영비, 유지보수비, 개발비)
- Backup & Recovery 기법이 어려움
- 시스템 취약성 (일부 고장이 전체 시스템 마비 가능)

6절 DBA (Database Administrator)
- 데이터베이스 시스템의 전체적인 운영관리를 책임지는 사람/집단
- 데이터베이스 설계와 운영, 행정 및 불평해결, 시스템 감시 및 성능분석 담당

7절 데이터 사전
- 데이터베이스 운영에 필요한 정보들의 집합
- DBMS에 의해 관리, 유지됨
- System Catalog라고도 부름
